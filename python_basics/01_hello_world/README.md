# 🐍 Урок 01: Hello World — Знакомство с Python

## 📖 Теория

### Что такое Python?

**Python** — это высокоуровневый, интерпретируемый язык программирования общего назначения. 
Создан Гвидо ван Россумом в 1991 году. Назван в честь телешоу «Monty Python's Flying Circus».

**Ключевые особенности Python:**
- 🐍 **Простой и читаемый синтаксис** — код похож на псевдокод
- 🧩 **Динамическая типизация** — не нужно объявлять типы переменных
- 📦 **Огромная стандартная библиотека** — «батарейки включены»
- 🔄 **Кроссплатформенность** — работает на Windows, Linux, macOS
- 🧵 **Мультипарадигменный** — ООП, функциональное, процедурное программирование

### Как работает Python?

```
Исходный код (.py) → Компиляция в байт-код (.pyc) → Интерпретация PVM (Python Virtual Machine)
```

В отличие от C/C++/Java — Python **не требует компиляции перед запуском**. 
Вы просто пишете код и запускаете его!

### Функция `print()`

`print()` — встроенная функция для вывода информации на экран (в консоль).

```python
print("Привет, мир!")        # Вывод строки
print(42)                     # Вывод числа
print("Ответ:", 42)           # Вывод нескольких аргументов (через запятую)
print("A", "B", "C", sep="-") # sep — разделитель между аргументами
print("Привет", end="!")      # end — что вывести в конце строки (по умолчанию \n)
```

### Функция `input()`

`input()` — читает ввод пользователя из консоли. Всегда возвращает **строку** (`str`).

```python
name = input("Введите ваше имя: ")  # Выводит подсказку и ждёт ввода
print(f"Привет, {name}!")           # f-строка для форматирования
```

### Комментарии в Python

```python
# Это однострочный комментарий

"""
Это многострочный комментарий (docstring).
Используется для документации функций, классов, модулей.
"""

x = 10  # Комментарий может быть и в конце строки
```

### Запуск Python-программы

**Способ 1: Интерактивный режим (REPL)**
```bash
python          # Запуск интерпретатора
>>> print("Hello")
Hello
>>> exit()      # Выход
```

**Способ 2: Запуск файла**
```bash
python main.py       # Windows
python3 main.py      # Linux/macOS
```

### Установка Python

1. Скачайте с [python.org](https://python.org/downloads/)
2. При установке **обязательно** отметьте галочку «Add Python to PATH»
3. Проверьте установку:
```bash
python --version
```

### Структура простой программы

```python
# 1. Импорты (если нужны)
# 2. Функции и классы (если нужны)
# 3. Основной код

def main():
    """Главная функция программы."""
    print("Программа запущена!")

if __name__ == "__main__":
    main()  # Выполнится только при прямом запуске файла
```

Конструкция `if __name__ == "__main__":` — стандартный паттерн Python. 
Код внутри выполнится только если файл запущен напрямую, но не при импорте как модуля.
