# 🐍 Урок 02: Переменные и типы данных

## 📖 Теория

### Что такое переменная?

**Переменная** — это именованная область памяти для хранения данных. В Python переменные не нужно объявлять заранее — они создаются при первом присваивании.

```python
x = 10        # Создали переменную x и присвоили ей значение 10
name = "Анна" # Переменная name хранит строку
```

**Важно:** В Python переменные — это **ссылки** на объекты в памяти, а не сами объекты. Одна и та же переменная может ссылаться на объекты разных типов:

```python
x = 10       # x ссылается на int
x = "hello"  # теперь x ссылается на str — это нормально!
```

### Правила именования переменных

```python
✅ Разрешено:
my_var = 1       # буквы, цифры, подчёркивания
_var = 2         # может начинаться с _
myVar = 3        # camelCase (но в Python не принят)
_ = 4            # _ часто используется для "ненужной" переменной
переменная = 5   # можно использовать кириллицу (но не рекомендуется)

❌ Запрещено:
1var = 1         # нельзя начинать с цифры
my-var = 2       # дефис запрещён
class = 3        # нельзя использовать ключевые слова
```

**Python naming convention (PEP 8):**
- `snake_case` для переменных и функций: `my_variable`, `calculate_total`
- `CamelCase` для классов: `MyClass`, `UserProfile`
- `UPPER_CASE` для констант: `MAX_SIZE`, `PI`

### Основные типы данных

| Тип | Ключевое слово | Пример | Описание |
|-----|---------------|--------|----------|
| **Целые числа** | `int` | `42`, `-7`, `0` | Целые числа неограниченной точности |
| **Дробные числа** | `float` | `3.14`, `-0.5`, `1e-5` | Числа с плавающей точкой |
| **Строки** | `str` | `"hello"`, `'привет'` | Текст (последовательность символов) |
| **Логический** | `bool` | `True`, `False` | Истина/Ложь |
| **None** | `NoneType` | `None` | Отсутствие значения (аналог null) |

### Как узнать тип? — функция `type()`

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
print(type(None))     # <class 'NoneType'>
```

### Приведение (конвертация) типов

```python
int("42")        # "42" → 42
float("3.14")    # "3.14" → 3.14
str(42)          # 42 → "42"
bool(0)          # 0 → False
bool(1)          # 1 → True
bool("")         # "" → False (пустая строка)
bool("hello")    # "hello" → True
```

### Функция `id()` — адрес объекта в памяти

```python
a = 10
print(id(a))  # Например: 140735290889512
b = a          # b ссылается на тот же объект
print(id(b))  # Тот же адрес!
```

### Функция `isinstance()` — проверка типа

```python
x = 42
isinstance(x, int)    # True
isinstance(x, str)    # False
isinstance(x, (int, float))  # True — можно проверять несколько типов
```

### Множественное присваивание

```python
a, b, c = 1, 2, 3       # a=1, b=2, c=3
x = y = z = 0            # x=0, y=0, z=0
a, b = b, a              # обмен значений (swap)
```

### `int` — целые числа

```python
# Python поддерживает целые числа произвольной длины!
big = 2 ** 1000  # Огромное число — без переполнения

# Системы счисления
binary = 0b1010    # 10 в двоичной
octal = 0o12       # 10 в восьмеричной
hex_num = 0xA      # 10 в шестнадцатеричной
```

### `float` — числа с плавающей точкой

```python
# Важно: float имеет ограниченную точность (IEEE 754)
0.1 + 0.2 == 0.3  # False! 0.1 + 0.2 = 0.30000000000000004

# Для точных вычислений используйте Decimal
from decimal import Decimal
Decimal('0.1') + Decimal('0.2') == Decimal('0.3')  # True

# Специальные значения
float('inf')   # бесконечность
float('-inf')  # минус бесконечность
float('nan')   # Not a Number
```

### `bool` — логический тип

```python
# True/False — это подкласс int!
True == 1    # True
False == 0   # True
True + True  # 2 (можно использовать как числа!)

# Что является False в Python?
bool(0)       # False
bool(0.0)     # False
bool("")      # False
bool([])      # False
bool({})      # False
bool(None)    # False
# ВСЁ остальное — True!
```
