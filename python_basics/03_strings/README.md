# 🐍 Урок 03: Строки (str)

## 📖 Теория

### Что такое строка?

**Строка** — неизменяемая (immutable) последовательность Unicode-символов. В Python строки — один из самых часто используемых типов данных.

```python
s = "Hello, World!"
```

### Создание строк

```python
s1 = "Двойные кавычки"
s2 = 'Одинарные кавычки'
s3 = """Многострочная
строка (тройные кавычки)"""
s4 = '''Тоже
многострочная'''
s5 = str(42)          # "42" — из числа
s6 = "O'Reilly"       # кавычки внутри
s7 = 'Сказал: "Привет"'  # или так
```

### Экранирование (escape-последовательности)

| Символ | Значение |
|--------|----------|
| `\n` | Перевод строки (newline) |
| `\t` | Табуляция (tab) |
| `\\` | Обратный слеш |
| `\'` | Одинарная кавычка |
| `\"` | Двойная кавычка |
| `\r` | Возврат каретки |
| `\uXXXX` | Unicode-символ по коду |

```python
print("Строка 1\nСтрока 2")          # Две строки
print("Колонка1\tКолонка2")          # С табуляцией
print("Путь: C:\\Users\\admin")      # Обратные слеши
```

**Raw-строки** — отключают экранирование:
```python
path = r"C:\Users\admin\Desktop"  # \ не экранируются!
```

### Индексация и срезы (slicing)

```python
s = "Python"
# Индексы:  0   1   2   3   4   5
#          -6  -5  -4  -3  -2  -1

s[0]      # 'P' — первый символ
s[-1]     # 'n' — последний символ
s[0:3]    # 'Pyt' — с 0 по 2 (3 не включается)
s[:3]     # 'Pyt' — от начала до 2
s[3:]     # 'hon' — с 3 до конца
s[::2]    # 'Pto' — каждый второй символ
s[::-1]   # 'nohtyP' — строка задом наперёд!
```

**Синтаксис среза:** `[start:stop:step]`
- `start` — начало (включительно, по умолчанию 0)
- `stop` — конец (НЕ включительно)
- `step` — шаг (по умолчанию 1)

### Строки НЕИЗМЕНЯЕМЫ (immutable)

```python
s = "hello"
s[0] = "H"  # ❌ TypeError! Нельзя изменить символ
s = "H" + s[1:]  # ✅ Создаём новую строку
```

### Конкатенация и повторение

```python
"Hello" + " " + "World"  # "Hello World" — склеивание
"Ha" * 3                 # "HaHaHa" — повторение
```

### f-строки (Python 3.6+)

```python
name = "Анна"
age = 25
print(f"Меня зовут {name}, мне {age} лет")
print(f"Через 5 лет будет {age + 5}")

# Форматирование чисел
pi = 3.14159265
print(f"π ≈ {pi:.2f}")         # 3.14
print(f"Процент: {0.856:.1%}")  # 85.6%

# Выравнивание
print(f"|{name:<10}|")   # Влево
print(f"|{name:>10}|")   # Вправо
print(f"|{name:^10}|")   # По центру
```

### Основные методы строк

| Метод | Описание | Пример |
|-------|----------|--------|
| `.upper()` | В верхний регистр | `"hello".upper()` → `"HELLO"` |
| `.lower()` | В нижний регистр | `"HELLO".lower()` → `"hello"` |
| `.capitalize()` | Первая буква заглавная | `"hello world".capitalize()` → `"Hello world"` |
| `.title()` | Каждое слово с заглавной | `"hello world".title()` → `"Hello World"` |
| `.strip()` | Убрать пробелы по краям | `"  hi  ".strip()` → `"hi"` |
| `.lstrip()` / `.rstrip()` | Убрать слева/справа | |
| `.replace(old, new)` | Заменить подстроку | `"hello".replace("e", "a")` → `"hallo"` |
| `.split(sep)` | Разбить на список | `"a,b,c".split(",")` → `["a", "b", "c"]` |
| `.join(iterable)` | Склеить список | `"-".join(["a","b","c"])` → `"a-b-c"` |
| `.find(sub)` | Индекс подстроки (-1 если нет) | `"hello".find("e")` → `1` |
| `.index(sub)` | Индекс (ValueError если нет) | |
| `.count(sub)` | Количество вхождений | `"banana".count("a")` → `3` |
| `.startswith(pref)` | Начинается с... | `"hello".startswith("he")` → `True` |
| `.endswith(suff)` | Заканчивается на... | `"hello".endswith("lo")` → `True` |
| `.isdigit()` | Все символы — цифры? | `"123".isdigit()` → `True` |
| `.isalpha()` | Все символы — буквы? | `"abc".isalpha()` → `True` |
| `.isalnum()` | Буквы + цифры? | `"abc123".isalnum()` → `True` |
| `.isspace()` | Только пробельные символы? | |

### Проверка вхождения (in)

```python
"ell" in "hello"     # True
"xyz" in "hello"     # False
"ell" not in "hello"  # False
```

### Длина строки

```python
len("Python")  # 6
len("Привет")  # 6
len("🐍")      # 1 (Python 3 правильно считает Unicode)
```
