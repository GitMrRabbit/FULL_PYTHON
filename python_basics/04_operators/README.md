# 🔢 Урок 04: Операторы в Python

## 📖 Теория

Операторы — это символы, которые выполняют операции над значениями (операндами). Python поддерживает 7 категорий операторов.

---

## 1️⃣ Арифметические операторы

| Оператор | Описание | Пример |
|----------|----------|--------|
| `+` | Сложение | `5 + 3 → 8` |
| `-` | Вычитание | `5 - 3 → 2` |
| `*` | Умножение | `5 * 3 → 15` |
| `/` | Деление (всегда float) | `5 / 2 → 2.5` |
| `//` | Целочисленное деление | `5 // 2 → 2` |
| `%` | Остаток от деления | `5 % 2 → 1` |
| `**` | Возведение в степень | `2 ** 3 → 8` |

---

## 2️⃣ Операторы присваивания

```python
x = 10       # Присваивание
x += 5       # x = x + 5
x -= 3       # x = x - 3
x *= 2       # x = x * 2
x /= 4       # x = x / 4
x //= 2      # x = x // 2
x %= 3       # x = x % 3
x **= 2      # x = x ** 2
```

**Множественное присваивание:**
```python
a, b = 1, 2           # a=1, b=2
a, b = b, a           # Swap!
x = y = z = 0         # Все три = 0
```

**Walrus operator `:=` (Python 3.8+):**
```python
# Присваивание внутри выражения
if (n := len(data)) > 10:
    print(f"Слишком много: {n}")
```

---

## 3️⃣ Операторы сравнения

| Оператор | Описание |
|----------|----------|
| `==` | Равно |
| `!=` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |

**Цепочки сравнений:**
```python
if 1 < x < 10:        # Эквивалентно: 1 < x and x < 10
    print("x в диапазоне")
```

---

## 4️⃣ Логические операторы

| Оператор | Описание | Результат True когда |
|----------|----------|---------------------|
| `and` | Логическое И | Оба операнда True |
| `or` | Логическое ИЛИ | Хотя бы один True |
| `not` | Логическое НЕ | Операнд False |

**Короткое замыкание (short-circuit evaluation):**
```python
# Если A ложно, B не вычисляется
if condition and expensive_check():
    ...

# Если A истинно, B не вычисляется
if is_admin or check_permissions():
    ...
```

**Правдивые (truthy) и ложные (falsy) значения:**
- **Falsy:** `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `set()`, `()`
- **Truthy:** всё остальное

---

## 5️⃣ Побитовые операторы

| Оператор | Описание | Пример |
|----------|----------|--------|
| `&` | Побитовое И | `5 & 3 → 1` |
| `\|` | Побитовое ИЛИ | `5 \| 3 → 7` |
| `^` | XOR (исключающее ИЛИ) | `5 ^ 3 → 6` |
| `~` | NOT (инверсия битов) | `~5 → -6` |
| `<<` | Сдвиг влево (`×2^n`) | `1 << 3 → 8` |
| `>>` | Сдвиг вправо (`÷2^n`) | `8 >> 2 → 2` |

---

## 6️⃣ Операторы идентичности и принадлежности

```python
# is / is not — проверка, тот же ли объект в памяти
a = [1, 2, 3]
b = [1, 2, 3]
a == b   # True  (значения равны)
a is b   # False (разные объекты в памяти)
a is not b  # True

# Для None ВСЕГДА используйте is
if x is None:          # ✅ Правильно
if x == None:          # ❌ Неправильно

# in / not in — проверка вхождения
if "a" in "abc":           # True
if 5 in [1, 2, 3, 4, 5]:  # True
if "key" in {"key": 1}:    # True (для словарей проверяет ключи)
```

## 7️⃣ Приоритет операторов (от высшего к низшему)

```
()                # Скобки
**                # Степень
~ + - (унарные)   # Унарный плюс/минус, NOT
* / // %          # Умножение, деление
+ -               # Сложение, вычитание
<< >>             # Побитовые сдвиги
&                 # Побитовое И
^                 # Побитовое XOR
|                 # Побитовое ИЛИ
== != > < >= <=   # Сравнения
is, is not, in, not in
not               # Логическое НЕ
and               # Логическое И
or                # Логическое ИЛИ
:=                # Walrus
```

## 💡 Продвинутые приёмы

### `any()` и `all()` — проверка коллекций
```python
any([False, False, True])  # True (хотя бы один)
all([True, True, False])   # False (не все)
```

### Условное присваивание через `or`
```python
name = user_input or "Гость"  # Если user_input пустой, "Гость"
```

### Побитовые флаги
```python
READ = 1   # 001
WRITE = 2  # 010
EXEC = 4   # 100
permissions = READ | WRITE   # 011
can_read = bool(permissions & READ)   # True
```
