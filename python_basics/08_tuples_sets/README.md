# 🎲 Урок 08: Кортежи и Множества в Python

## 📖 Теория

### Кортеж (`tuple`) — неизменяемая последовательность
### Множество (`set`) — неупорядоченная коллекция уникальных элементов

---

## Часть 1: Кортежи (`tuple`)

### Создание
```python
t = (1, 2, 3)
t = 1, 2, 3           # Скобки не обязательны!
t = (1,)               # Кортеж из одного элемента (запятая обязательна!)
t = tuple([1, 2, 3])   # Из списка
t = tuple("hello")     # ('h', 'e', 'l', 'l', 'o')
```

### Свойства
- **Неизменяемость**: нельзя добавить/удалить/изменить элемент
- **Упорядоченность**: элементы имеют фиксированный порядок
- **Хешируемость**: можно использовать как ключи словаря (если все элементы хешируемы)
- **Занимают меньше памяти**, чем списки

### Распаковка (unpacking)
```python
t = (1, 2, 3)
a, b, c = t            # a=1, b=2, c=3

# Расширенная распаковка (Python 3)
first, *middle, last = (1, 2, 3, 4, 5)
# first=1, middle=[2,3,4], last=5

# Обмен значений (swap)
a, b = b, a            # Работает через неявный кортеж!
```

### `namedtuple` — именованный кортеж
```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x, p.y)        # 10 20
print(p[0], p[1])      # 10 20 (доступ по индексу тоже работает!)

# С значениями по умолчанию (Python 3.7+)
Point3D = namedtuple("Point3D", ["x", "y", "z"], defaults=[0])
p = Point3D(1, 2)      # Point3D(x=1, y=2, z=0)

# Из словаря
d = {"x": 5, "y": 10}
p = Point(**d)          # Point(x=5, y=10)

# Преобразование
p._asdict()             # OrderedDict([('x', 10), ('y', 20)])
p._replace(x=99)        # Новый кортеж с изменённым x
```

## Часть 2: Множества (`set`)

### Создание
```python
s = {1, 2, 3}
s = set()               # Пустое множество ({} — это словарь!)
s = set([1, 2, 2, 3])   # {1, 2, 3} (дубликаты удалены)
```

### Свойства
- **Уникальность**: каждый элемент только один раз
- **Неупорядоченность**: порядок не гарантирован
- **Изменяемость**: можно добавлять/удалять элементы
- **Только хешируемые элементы**: списки и словари нельзя

### Операции над множествами
```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# Основные операции
a | b        # Объединение: {1, 2, 3, 4, 5, 6}
a & b        # Пересечение: {3, 4}
a - b        # Разность: {1, 2}
a ^ b        # Симметрическая разность: {1, 2, 5, 6}

# Проверки
a <= b       # a — подмножество b?
a >= b       # a — надмножество b?
a.isdisjoint(b)  # Нет общих элементов?
```

### Методы множеств
```python
s.add(x)           # Добавить элемент
s.remove(x)        # Удалить (ошибка, если нет)
s.discard(x)       # Удалить (без ошибки)
s.pop()            # Удалить и вернуть случайный элемент
s.clear()          # Очистить

# Обновление
s.update(iter)     # Добавить все элементы (как |)
s.intersection_update(iter)  # Оставить только общие (как &)
s.difference_update(iter)    # Удалить элементы из iter (как -)
```

### `frozenset` — неизменяемое множество
```python
fs = frozenset([1, 2, 3])
# fs.add(4)  # AttributeError! Нельзя изменить
# Можно использовать как ключ словаря
d = {fs: "value"}

# Хешируемость
hash(fs)     # Работает
hash({1,2})  # TypeError: set не хешируется
```

## 📊 Сравнение коллекций

| Свойство | list | tuple | set | frozenset |
|----------|------|-------|-----|-----------|
| Изменяемость | ✅ | ❌ | ✅ | ❌ |
| Упорядоченность | ✅ | ✅ | ❌ | ❌ |
| Дубликаты | ✅ | ✅ | ❌ | ❌ |
| Индексация | ✅ | ✅ | ❌ | ❌ |
| Ключ словаря | ❌ | ✅* | ❌ | ✅* |

*При условии, что все элементы хешируемы.

---

## ⚡ Производительность

```python
# Проверка вхождения: O(1) для set, O(n) для list
if x in my_set:     # Мгновенно для миллионов элементов
    ...

# Удаление дубликатов
unique = list(set(duplicates))  # Быстро, но порядок теряется!
unique = list(dict.fromkeys(duplicates))  # С сохранением порядка (Python 3.7+)
```
