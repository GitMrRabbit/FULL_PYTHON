# 🔍 Урок 24: Регулярные выражения (Regex)

## 📖 Основные функции

```python
import re

re.search(pattern, text)      # Первое совпадение (Match-объект или None)
re.match(pattern, text)       # Только начало строки
re.findall(pattern, text)     # Список всех совпадений
re.finditer(pattern, text)    # Итератор Match-объектов
re.sub(pattern, repl, text)   # Замена
re.split(pattern, text)       # Разделение
```

---

## 🔹 Символы и классы

| Символ | Значение | Пример |
|--------|----------|--------|
| `.` | Любой символ (кроме \n) | `h.t` → hat, hot |
| `\d` | Цифра [0-9] | `\d+` → 123 |
| `\w` | Буква/цифра/_ | `\w+` → hello_1 |
| `\s` | Пробельный символ | `\s+` → пробелы |
| `[abc]` | Один из | `[aeiou]` → гласные |
| `[^abc]` | НЕ один из | `[^0-9]` → не цифры |
| `^`, `$` | Начало/конец строки | `^Hello`, `world$` |
| `\b` | Граница слова | `\bcat\b` → cat, не cats |

---

## 🔹 Квантификаторы

| Символ | Повторений | Жадный | Ленивый |
|--------|-----------|--------|---------|
| `*` | 0+ | `.*` | `.*?` |
| `+` | 1+ | `.+` | `.+?` |
| `?` | 0-1 | `.?` | `.??` |
| `{n}` | ровно n | — | — |
| `{n,m}` | n-m | `.{n,m}` | `.{n,m}?` |

---

## 🔹 Группы

```python
(\w+)@(\w+\.\w+)                    # Нумерованные группы: 1=user, 2=domain
(?P<user>\w+)@(?P<domain>\w+\.\w+)  # Именованные группы

\1, \2                              # Ссылки на группы (поиск повторений)
re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3.\2.\1", "2024-06-15")  # → 15.06.2024
```

---

## 🔹 Флаги

```python
re.IGNORECASE  # re.I — игнорировать регистр
re.MULTILINE   # re.M — ^ и $ работают на каждой строке
re.DOTALL      # re.S — . включает \n
re.VERBOSE     # re.X — игнорировать пробелы и комментарии (#)
```

---

## 🔹 Компиляция

```python
pattern = re.compile(r"\d{4}-\d{2}-\d{2}")  # Предкомпиляция (быстрее для многократного)
pattern.match(text)
```
