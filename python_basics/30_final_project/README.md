# 🏆 Урок 30: Финальный проект — Менеджер задач

## 📖 О проекте

Консольное приложение, объединяющее все знания курса:
- ООП: классы Task, TaskRepository, TaskManagerApp
- dataclass, Enum (Priority, Status)
- JSON-сериализация (сохранение/загрузка)
- Работа с датами (просроченные задачи)
- Comprehensions (фильтрация, поиск)
- Type Hints везде
- Обработка исключений

---

## 🔹 Команды

```
list [status]  — Показать задачи
add            — Добавить задачу
done <id>      — Отметить выполненной
delete <id>    — Удалить задачу
search <query> — Поиск
stats          — Статистика
save           — Сохранить в JSON
```

---

## 🔹 Структура

```
Task (dataclass)        — модель данных
TaskRepository          — CRUD + фильтрация + поиск + сохранение
TaskManagerApp          — консольный интерфейс
```
