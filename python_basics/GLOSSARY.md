# 📖 Глоссарий Python — простыми словами

> Если встретили незнакомый термин — найдите его здесь. Все объяснения написаны
> для человека, который слышит это впервые.

---

## А

**Аргумент (argument)** — значение, которое передают в функцию при вызове.
```python
print("Привет")  # "Привет" — аргумент
```

**Атрибут (attribute)** — переменная, привязанная к объекту.
```python
"hello".upper  # .upper — атрибут строки
obj.name       # .name — атрибут объекта
```

**Асинхронность (async)** — способ делать несколько задач «одновременно» без потоков.
Ключевые слова: `async`, `await`.

---

## Б

**Библиотека (library)** — набор готовых функций и классов. То же что «модуль» или «пакет».
```python
import math  # math — библиотека математических функций
```

**Бесконечный цикл** — цикл, который никогда не завершается сам. Обычно ошибка.
```python
while True:
    print("Это бесконечно!")  # Нажми Ctrl+C чтобы остановить
```

**Булево значение (bool)** — `True` (истина) или `False` (ложь).
Названо в честь математика Джорджа Буля.

---

## В

**Виртуальное окружение (venv)** — изолированная «песочница» для Python-проекта.
У каждого проекта своё окружение со своими библиотеками, чтобы они не конфликтовали.

**Выражение (expression)** — кусок кода, который вычисляется в значение.
```python
2 + 3          # выражение → 5
x > 10         # выражение → True или False
"Hello" + "!"  # выражение → "Hello!"
```

---

## Г

**Генератор (generator)** — функция с `yield`, которая выдаёт значения по одному,
не храня всю последовательность в памяти.
```python
def gen():
    yield 1
    yield 2
    yield 3
```

**Глобальная переменная** — переменная, доступная во всей программе.
Обычно их избегают — лучше передавать значения через параметры функций.

---

## Д

**Декоратор (decorator)** — функция, которая «оборачивает» другую функцию,
добавляя поведение до/после её вызова. Пишется с `@`.
```python
@logger
def my_func():
    pass
```

**Документация (docstring)** — строка в начале функции/класса, объясняющая что он делает.
```python
def add(a, b):
    """Складывает два числа и возвращает результат."""
    return a + b
```

---

## З

**Замыкание (closure)** — функция, которая «помнит» переменные из внешней области видимости,
даже после завершения внешней функции.

---

## И

**Импорт (import)** — подключение модуля или библиотеки.
```python
import math
from datetime import datetime
```

**Индекс (index)** — номер элемента в списке/строке. **Начинается с 0!**
```python
name = "Python"
name[0]  # 'P' (не 'y'!)
name[5]  # 'n'
name[-1] # 'n' (последний)
```

**Исключение (exception)** — ошибка во время выполнения программы.
Можно перехватывать и обрабатывать через `try/except`.

**Итератор (iterator)** — объект, по которому можно пройти в цикле `for`.
Списки, строки, словари — всё это итераторы.

**Итерация (iteration)** — один проход цикла.
```python
for i in range(3):  # 3 итерации
    print(i)
```

---

## К

**Класс (class)** — шаблон для создания объектов. Описывает какие данные (атрибуты)
и поведение (методы) будут у объектов этого типа.

**Ключ (key)** — в словаре: то, по чему ищут значение.
```python
user = {"name": "Анна", "age": 28}
# "name", "age" — ключи
# "Анна", 28 — значения
```

**Коллекция (collection)** — тип данных, который хранит несколько элементов.
Список, кортеж, множество, словарь.

**Комментарий (comment)** — текст в коде, который Python игнорирует. Для людей.
```python
# Это комментарий
x = 10  # И это тоже
```

**Контекстный менеджер (context manager)** — конструкция `with`, которая
автоматически открывает и закрывает ресурсы (файлы, соединения).
```python
with open("file.txt") as f:  # Файл закроется сам
    data = f.read()
```

**Кортеж (tuple)** — как список, но **нельзя изменить** (неизменяемый).
```python
point = (3, 4)   # Кортеж из двух чисел
point[0] = 5     # ОШИБКА! Нельзя изменить
```

---

## Л

**Логическое выражение** — выражение, которое даёт `True` или `False`.
```python
x > 10         # True если x больше 10
name == "Анна" # True если name равно "Анна"
is_admin and is_active  # True если оба True
```

---

## М

**Магический метод (dunder)** — специальный метод вида `__имя__`, который
Python вызывает автоматически: `__init__`, `__str__`, `__len__` и т.д.

**Массив (array)** — то же что список. В Python чаще говорят «список» (list).

**Метод (method)** — функция, привязанная к объекту/классу.
```python
"hello".upper()  # .upper() — метод строки
my_list.append(5) # .append() — метод списка
```

**Множество (set)** — коллекция **уникальных** элементов (без дубликатов).
Порядок не гарантирован.
```python
{1, 2, 3, 3}  # Результат: {1, 2, 3}
```

**Модуль (module)** — файл `.py` с кодом, который можно импортировать.

**Мок (mock)** — «заглушка» для тестирования. Подменяет реальный объект
и позволяет проверить как он использовался.

---

## Н

**Наследование (inheritance)** — создание нового класса на основе существующего.
Новый класс получает все методы и атрибуты родителя.
```python
class Dog(Animal):  # Dog наследует Animal
    pass
```

**None** — специальное значение «ничего» / «пусто». Аналог `null` в других языках.

---

## О

**Объект (object)** — конкретный экземпляр класса.
```python
alice = Person("Алиса", 28)  # alice — объект класса Person
```

**Область видимости (scope)** — часть программы, где переменная доступна.
Правило LEGB: Local → Enclosing → Global → Built-in.

**ООП (ООП)** — Объектно-Ориентированное Программирование. Подход, где программа
состоит из объектов, которые обмениваются сообщениями.

**Оператор (operator)** — символ, выполняющий операцию: `+`, `-`, `==`, `in`, `and` и т.д.

**Очередь (queue)** — структура «первым пришёл — первым ушёл» (FIFO).

---

## П

**Пакет (package)** — директория с模块ями Python. Содержит `__init__.py`.

**Параметр (parameter)** — переменная в определении функции.
```python
def greet(name):  # name — параметр
    print(f"Привет, {name}")
```

**Переменная (variable)** — именованная ячейка для хранения данных.
```python
x = 10        # x — переменная, 10 — значение
name = "Анна"
```

**Полиморфизм (polymorphism)** — возможность использовать объекты разных классов
через одинаковый интерфейс.

**Поток (thread)** — способ выполнять код «параллельно» в рамках одного процесса.

---

## Р

**Рекурсия (recursion)** — функция, которая вызывает саму себя.
Требует условие выхода, иначе бесконечный цикл.

**Рефакторинг (refactoring)** — улучшение кода без изменения его поведения.

**Регулярное выражение (regex)** — язык поиска и замены текста по шаблону.

---

## С

**Словарь (dict)** — коллекция пар «ключ → значение».
```python
user = {"name": "Анна", "age": 28}
user["name"]  # "Анна"
```

**Список (list)** — упорядоченная изменяемая коллекция.
```python
fruits = ["яблоко", "банан", "киви"]
fruits[0]  # "яблоко"
```

**Стек (stack)** — структура «последним пришёл — первым ушёл» (LIFO).

**Строка (str)** — последовательность символов.
```python
name = "Python"
len(name)  # 6
```

---

## Т

**Тернарный оператор** — сокращённый `if/else` в одну строку.
```python
status = "Взрослый" if age >= 18 else "Ребёнок"
```

**Тип данных (type)** — категория значения: `int` (целое), `str` (строка),
`bool` (True/False), `list` (список) и т.д.

**Транзакция (transaction)** — группа операций с БД, которые либо все выполняются,
либо все отменяются.

---

## Ф

**Фикстура (fixture)** — в pytest: функция, которая подготавливает данные
или окружение для теста.

**Фреймворк (framework)** — набор готовых инструментов и правил для разработки.

**Функция (function)** — именованный блок кода, который можно переиспользовать.
```python
def add(a, b):
    return a + b
```

---

## Ц

**Цикл (loop)** — конструкция для повторения блока кода.
`for` — когда знаем сколько раз, `while` — пока условие истинно.

---

## Ч

**Чувствительность к регистру (case-sensitive)** — Python различает заглавные
и строчные буквы: `name`, `Name`, `NAME` — три разные переменные.

---

## Э

**Экземпляр (instance)** — то же что «объект». Конкретная реализация класса.

---

## API

**API (Application Programming Interface)** — способ взаимодействия программ.
REST API — общение через HTTP-запросы (GET, POST, PUT, DELETE).

---

## CRUD

**Create, Read, Update, Delete** — четыре базовые операции с данными:
создать, прочитать, обновить, удалить.

---

## CSV

**Comma-Separated Values** — текстовый формат для таблиц. Значения разделены запятыми.

---

## DTO

**Data Transfer Object** — объект для переноса данных между слоями приложения.

---

## GIL

**Global Interpreter Lock** — глобальная блокировка Python. Позволяет только одному
потоку выполнять Python-код одновременно. Поэтому для вычислений используют процессы.

---

## JSON

**JavaScript Object Notation** — текстовый формат обмена данными. Главный формат
для API в интернете.

---

## MRO

**Method Resolution Order** — порядок, в котором Python ищет методы при
множественном наследовании.

---

## ORM

**Object-Relational Mapping** — способ работать с БД через Python-объекты
вместо SQL-запросов.

---

## POM

**Page Object Model** — паттерн в тестировании: каждая страница сайта
представлена как отдельный класс.

---

## SQL

**Structured Query Language** — язык запросов к базам данных.
