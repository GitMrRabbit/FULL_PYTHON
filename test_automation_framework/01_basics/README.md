# 🧪 Уровень 1: Азы автоматизации тестирования

## 📖 Что такое тестирование?

**Тестирование ПО** — процесс проверки соответствия программы требованиям и выявления ошибок.

### Виды тестирования

```
                    ┌─────────────────────────┐
                    │     ТЕСТИРОВАНИЕ         │
                    └───────────┬─────────────┘
                                │
            ┌───────────────────┼───────────────────┐
            │                   │                   │
    ┌───────▼───────┐   ┌──────▼──────┐   ┌────────▼────────┐
    │  Ручное       │   │ Автомати-   │   │  Исследова-     │
    │  тестирование │   │ зированное  │   │  тельское       │
    └───────────────┘   └──────┬──────┘   └─────────────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
     ┌────────▼────────┐ ┌────▼─────┐ ┌────────▼────────┐
     │  Модульное      │ │Интегра-  │ │  End-to-End     │
     │  (Unit)         │ │ционное   │ │  (E2E)          │
     └─────────────────┘ └──────────┘ └─────────────────┘
```

### Пирамида тестирования

```
        ┌──────┐
        │ E2E  │  ← Мало тестов, медленные, дорогие
       ┌┴──────┴┐
       │  Интег- │ ← Среднее количество
       │ рационные│
      ┌┴──────────┴┐
      │  Модульные  │ ← МНОГО тестов, быстрые, дешёвые
      │  (Unit)     │
      └─────────────┘
```

### Pytest — главный инструмент

**Pytest** — самый популярный фреймворк для тестирования в Python.

Установка:
```bash
pip install pytest
```

Запуск тестов:
```bash
pytest                           # Все тесты в текущей директории
pytest test_file.py              # Конкретный файл
pytest test_file.py::test_func   # Конкретный тест
pytest -v                        # Подробный вывод
pytest -k "keyword"              # Тесты, содержащие keyword в имени
pytest -m "marker_name"          # Тесты с определённым маркером
pytest -x                        # Остановиться после первой ошибки
pytest --tb=short                # Короткий traceback
pytest -s                        # Показать print() в тестах
```

### AAA Pattern (Arrange-Act-Assert)

```python
def test_example():
    # Arrange — подготовка данных
    a, b = 2, 3

    # Act — действие
    result = a + b

    # Assert — проверка
    assert result == 5
```
